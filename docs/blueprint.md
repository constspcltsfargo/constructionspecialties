# **App Name**: Construction Specialties

## Core Features:

- Homepage with Navigation: Displays key sections like Hero, Services, Why Us, Blog, Contact with a responsive navigation bar.
- Service Overview: Presents roofing services in a grid with icons, descriptions, and links.
- Trust Indicators: Highlights key trust elements such as ratings and warranties.
- Testimonials Carousel: Displays client testimonials.
- Blog Section: Displays recent blog posts with images, excerpts, and links.
- Call to Action: A contrasting section encouraging users to schedule a roof inspection.
- Contact Form Submission Analyzer: Uses an AI tool to understand user input on the contact form and routes request to an appropriate team to accelerate the process. Uses location data if available to suggest nearby branches.

## Style Guidelines:

- Primary color: Deep blue (#304A7E) to convey trust and stability, reflective of reliable roofing services.
- Background color: Very light gray (#F0F2F5), providing a clean, neutral backdrop that highlights the content.
- Accent color: Warm orange (#E07A5F) for call-to-action buttons, offering a bright contrast against the blue and drawing attention.
- Body and headline font: 'Inter', a sans-serif typeface, for a modern, clean and readable look.
- Use clean, modern icons to represent services and benefits.
- Use a grid-based layout for service listings and blog posts to maintain consistency and readability.
- Subtle fade-in animations for sections to create a smooth user experience.
